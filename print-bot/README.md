# Print bot

Студент отправляет файл боту → выбирает копии / цвет / стороны → платит (перевод с чеком или наличные) →
оператор нажимает «Оплачено» → файл печатается на принтере.

## Запуск
1. `pip install -r requirements.txt`
2. Для DOCX/PPTX/XLSX установить LibreOffice (`soffice` в PATH). Для Windows — ещё SumatraPDF.
3. `cp .env.example .env` и заполнить (токен от @BotFather, ID админов, цены, карта).
4. Принтер должен быть настроен в системе (CUPS на Linux/Mac, обычный принтер в Windows).
5. `python bot.py` — запускать на компьютере, к которому подключён принтер.

Команда `/stats` (для админов) — статистика за сегодня.
